## 📌 3. Most Repeated BEU Java Exam PYQ Questions

Bihar Engineering University (BEU) semester exams me Java se aksar pooche jane wale questions:

1. **OOP Features:** Explain Abstraction, Encapsulation, Inheritance, and Polymorphism with real-world Java examples.
2. **JVM vs JRE vs JDK:** Differentiate between JVM, JRE, and JDK with architecture diagrams.
3. **Constructors:** What is Constructor Overloading? Explain `this()` and `super()` keywords with code.
4. **Interfaces vs Abstract Classes:** Key differences between interface and abstract class in Java. Why does Java not support multiple inheritance with classes?
5. **Exception Handling:** Explain `try`, `catch`, `finally`, `throw`, and `throws`. How to create a user-defined custom exception?
6. **Multithreading:** Difference between extending `Thread` class and implementing `Runnable` interface. Explain Thread Life Cycle and thread synchronization.
7. **Java Collections:** Explain ArrayList vs LinkedList vs Vector. Explain HashMap working principle.
8. **JDBC:** What are the steps to connect a Java application to a MySQL database using JDBC?
