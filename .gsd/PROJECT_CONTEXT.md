# Apna College Bihar - Project Context

## Project Overview
Apna College Bihar is an all-in-one educational platform for engineering and technical students across Bihar (specifically targeting BEU - Bihar Engineering University, AKU, and affiliated colleges).

## Technology Stack
- **Frontend**: React, Vite, Tailwind CSS / Vanilla CSS, Lucide Icons, Axios.
- **Backend**: Node.js, Express, REST APIs.
- **Database**: Firebase Firestore, Cloud Storage.
- **Automation / Scraping**: Puppeteer, BEU Notice Crawler, WhatsApp Auto-Broadcaster (`@wppconnect-team/wppconnect`).
- **Desktop**: Electron Windows app (`electron-main.js`).
- **Deployment**: Render (Backend), Vercel & Netlify (Frontend).

## Core Modules
1. **BEU Notice Broadcaster**: Scrapes official Bihar Engineering University notices and broadcasts alerts to student WhatsApp groups.
2. **PYQ & Syllabus Repository**: Past Year Questions and syllabus PDFs for all semesters & branches.
3. **Admin Panel**: Role-based management for study materials, notices, and WhatsApp broadcast sessions.
4. **Mentorship & Counselling**: Bihar UGEAC / BCECE counselling guidance for engineering admissions.
